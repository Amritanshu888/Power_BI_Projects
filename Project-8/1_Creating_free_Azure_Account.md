# Creating a Free Azure Account — Detailed Notes

## 1. Introduction

This session explains how to create a **free Azure account**.

The instructor mentions that the Azure signup link will be provided in the **description box/resource section**, from where it can be accessed.

The overall process involves:

1. Opening the Azure Free Account page.
2. Creating/signing into a Microsoft account.
3. Verifying the email address.
4. Providing personal/contact details.
5. Verifying the phone number.
6. Providing address information.
7. Accepting the terms and conditions.
8. Providing credit/debit card details.
9. Completing identity/OTP verification.
10. Accessing the Azure Portal.

---

# 2. Open the Azure Free Account Page

Once you access the provided Azure link:

1. Open the **Azure Free Account** page.
2. Click on:

**`Try Azure for free`**

The page may take some time to load.

---

# 3. Sign In or Create a Microsoft Account

Azure requires an account to continue.

You will be asked to provide:

* Email address
* Password

If you don't already have an account:

1. Click **`No account?`**
2. Click **`Create one`**.
3. Enter your email address.
4. Click **`Next`**.
5. Provide the required account details.
6. Continue to the verification step.

### Important

You can use your own email address when creating the account. The instructor uses an email address for demonstration purposes.

---

# 4. Verify Your Email Address

After entering the email address, Microsoft sends a **verification code** to that email address.

### Steps

1. Open the email account associated with the signup.
2. Find the verification email from Microsoft.
3. Copy the verification code.
4. Enter the code on the Azure signup page.
5. Click **`Next`**.
6. Complete the verification.

The instructor demonstrates this using a verification code.

> **Note:** The code shown in the lecture is only a demonstration code and should not be reused.

Once the code is accepted, the email verification is complete.

---

# 5. Provide Your Personal Details

After email verification, Azure asks for additional information.

You need to provide the required details in the signup form.

The instructor demonstrates entering information such as:

* First name
* Last name
* Email address
* Phone number
* Company name
* Address
* City
* State
* Postal code

The instructor initially enters a test account name and then provides the required information.

### Example fields

| Field        | Information to provide                        |
| ------------ | --------------------------------------------- |
| First Name   | Your first name                               |
| Last Name    | Your last name                                |
| Email        | Your email address                            |
| Phone Number | Your valid phone number                       |
| Company      | Company/organization information if requested |
| Address      | Your address                                  |
| City         | Your city                                     |
| State        | Your state                                    |
| Postal Code  | Your postal/ZIP code                          |

---

# 6. Verify Your Phone Number

Azure also requires phone-number verification.

### Steps

1. Enter your valid phone number.
2. Select the option to receive a verification message.
3. Microsoft sends a **verification code/OTP** to your phone.
4. Enter the received code.
5. Verify the phone number.

The instructor specifically demonstrates verification through a text message.

---

# 7. Provide Address Information

Next, provide your address details.

The required information includes:

* Address
* City
* State
* Postal code

Make sure the information is accurate because it is part of the account registration process.

---

# 8. Accept Terms and Conditions

Before continuing:

1. Review the applicable terms and conditions.
2. Select the checkbox indicating that you agree to the terms.
3. Click **`Next`**.

The signup process may take some time after this step.

---

# 9. Provide Credit/Debit Card Details

Azure asks for **credit or debit card information** during account registration.

### Steps

1. Enter your credit/debit card details.
2. Provide all other requested billing/payment information.
3. Review the information entered.
4. Continue with the signup process.

The instructor indicates that the card details are required for verification/signup.

### Important

The lecture is demonstrating the account creation process. **Never share your card number, CVV, OTP, password, or other sensitive information with anyone.**

---

# 10. Click Sign Up

After entering the required payment and account information:

1. Review the details.
2. Click **`Sign up`**.

The process may take some time while Microsoft processes the registration.

---

# 11. Complete OTP / Identity Verification

During the signup process, Microsoft may require additional verification.

The instructor demonstrates an **OTP-based identity verification** step.

### Steps

1. Wait for Microsoft to send the verification code.
2. Enter the received code.
3. Click **`Submit`** or **`Verify`**, depending on the screen shown.
4. Wait for the verification process to complete.

The instructor receives another verification code during the demonstration.

> **Note:** OTPs shown in the lecture are temporary and are not relevant to your own account.

---

# 12. Verify Identity

After entering the verification code, Azure displays an identity verification step.

The instructor:

1. Receives the verification code.
2. Enters the code.
3. Clicks **`Verify`**.
4. Waits for the verification process to complete.

Once the verification is successful, the Azure account setup is completed.

---

# 13. Go to Azure Portal

After successful registration and verification:

1. Click **`Go to Azure Portal`**.

This takes you to the **Microsoft Azure Portal**, where you can access Azure services and resources.

The Azure Portal is the primary web-based interface through which you can create and manage Azure resources.

---

# 15. Important Points from the Lecture

### Azure account creation

* Azure provides an option to create a **free account**.
* The signup link can be accessed through the lecture's **description/resource section**.
* A Microsoft account is required.
* If you don't have one, you can create it during the signup process.

### Verification

There are multiple verification steps:

* **Email verification**
* **Phone-number verification**
* **Identity/OTP verification**

### Account information

You may need to provide:

* Name
* Email
* Phone number
* Company information
* Address
* City
* State
* Postal code

### Payment information

* Credit/debit card details are requested during registration.
* Payment information should be entered carefully.
* Never share your card details or OTP with anyone.

### Azure Portal

Once registration is complete, select:

**`Go to Azure Portal`**

This gives you access to the Azure environment.
