# Power BI Desktop — Download & Installation Notes

## 1. Introduction to Power BI Desktop

**Microsoft Power BI Desktop** is a **companion desktop application for Power BI**.

Power BI consists of multiple components/elements, and **Power BI Desktop is one of the major components** used for developing reports and data models.

The main purpose of Power BI Desktop is to:

* Bring/import data into Power BI
* Transform and work with data
* Create relationships between data
* Build and enrich data models
* Create calculations and metrics
* Create reports using visualizations
* Save reports locally
* Publish reports to **Power BI Service**

---

# 2. Major Features of Power BI Desktop

The lecture highlights several important capabilities of Power BI Desktop.

### A. Get Data

Power BI Desktop allows you to **bring data into Power BI** from different sources.

This is done using the:

> **Get Data** option

Data can then be used for analysis and reporting.

The detailed process of importing and working with different data sources will be covered later in the course.

---

### B. Create Relationships

Power BI Desktop allows you to:

* Create relationships between tables
* Connect different datasets
* Build a proper data model

Relationships become particularly important when working with multiple tables.

---

### C. Enrich the Data Model

Power BI Desktop allows you to enrich your data model with:

* New data
* Different data formats
* Metrics/calculations

These capabilities help create a more useful model for analysis.

The detailed concepts will be covered when the course begins working with Power BI Desktop.

---

### D. Creating Reports

Power BI Desktop allows you to create reports using **visuals/visualizations**.

For example, reports can contain:

* Charts
* Tables
* Graphs
* Other visual elements

These visuals help represent data in an understandable manner.

---

### E. Saving Reports

The work created in Power BI Desktop can be saved locally.

Power BI Desktop reports are saved using the:

> **`.pbix` extension**

So, a Power BI Desktop report file will generally look like:

```text
ReportName.pbix
```

The `.pbix` file contains the Power BI report and its associated development work.

---

### F. Publishing Reports to Power BI Service

After creating a report in Power BI Desktop, it can be **published to Power BI Service**.

This introduces another important component of Power BI:

> **Power BI Service**

A simplified workflow is:

```text
Data
  ↓
Power BI Desktop
  ↓
Data Model
  ↓
Visualizations / Report
  ↓
Save as .PBIX
  ↓
Publish
  ↓
Power BI Service
```

The course will discuss Power BI Service and publishing in greater detail in upcoming sessions.

# 11. Important Points to Remember

### Power BI Desktop

* It is a **desktop application** that is part of the Power BI ecosystem.
* It is primarily used for developing reports and data models.
* Data can be imported using **Get Data**.
* Relationships can be created between tables.
* Data models can be enriched with additional data, formats and metrics.
* Reports are created using **visuals**.
* Power BI Desktop files use the **`.pbix` extension**.
* Reports can be published to **Power BI Service**.

### Installation

* Select the desired language.
* Download the appropriate executable file.
* Run the Power BI Desktop setup.
* Accept the license agreement.
* Continue with **Next**.
* Click **Install**.
* Wait for installation to finish.
* Check **Launch Microsoft Power BI Desktop**.
* Click **Finish**.

### Sign-In

* Sign-in is **not required for many basic Power BI Desktop activities**.
* You can click **Cancel** when the sign-in prompt appears.
* Some visuals/features may require sign-in, which will be covered later.

## 12. Key Concepts Introduced in This Lecture

| Concept                 | Meaning                                                               |
| ----------------------- | --------------------------------------------------------------------- |
| **Power BI Desktop**    | Desktop application used to develop Power BI reports and data models  |
| **Get Data**            | Used to bring/import data into Power BI                               |
| **Data Model**          | Structured model containing tables, relationships, calculations, etc. |
| **Relationships**       | Connections between tables                                            |
| **Visuals**             | Charts and other graphical representations of data                    |
| **PBIX**                | File format used for Power BI Desktop reports                         |
| **Power BI Service**    | Power BI's service where reports can be published and consumed        |
| **System Requirements** | Hardware/software requirements needed to run Power BI Desktop         |
| **License Agreement**   | Terms that must be accepted during installation                       |

### One-line takeaway

> **Power BI Desktop is the primary development environment where you import data, build data models, create visual reports, save them as `.pbix` files, and eventually publish them to Power BI Service.**
