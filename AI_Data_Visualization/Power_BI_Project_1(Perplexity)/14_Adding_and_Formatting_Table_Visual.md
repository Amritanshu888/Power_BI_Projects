# Power BI Notes: Creating a Top 10 Diamonds Table and Reusing Slicers

## 1. Objective of the Session

In this session, the next visual recommended in the PDF is created.

The approach is slightly different from the previous visuals:

1. A **DAX table expression** is provided in the PDF.
2. That DAX expression is used to create a **new calculated table** in Power BI.
3. The new table contains the **Top 10 Diamonds** data.
4. A **Table Visual** is then used to display the data.
5. Additional columns such as **Carat, Price, and Color** can be added.
6. Formatting is copied from an existing Matrix Visual using **Format Painter**.
7. Existing **Length, Width, and Height slicers** from the previous page are copied to the new page.
8. The slicers are intentionally **not synchronized** between the pages.

---

# 2. Create a New Table Using DAX

The PDF contains a DAX expression intended to generate the Top 10 Diamonds table.

The exact expression is copied directly from the PDF.

### Process

1. Open the PDF containing the recommended DAX expression.
2. Select/copy the complete DAX expression.
3. Return to **Power BI Desktop**.

# 11. Step 8 — Add Carat to the Table

### Process

3. Place it in the **Columns** bucket.

---

# 12. Step 9 — Turn Off Summarization for Carat

By default, Power BI may try to summarize numerical fields.

For example, it may show:

**Sum of Carat**

But for a Top 10 detail table, the goal is to show the **actual individual carat values**, not their sum.

Therefore, summarization should be disabled.

### Process

1. Click the dropdown next to the `Carat` field in the visual's field well.
2. Select:

**Don't summarize**

Now Power BI displays the actual carat value for each row.

---

# 13. Why "Don't Summarize" Is Important

A Top 10 detail table should show individual records.

For example:

| Carat |
| ----: |
|  1.52 |
|  2.01 |
|  1.75 |
|  1.20 |

You generally do **not** want:

| Sum of Carat |
| -----------: |
|         6.48 |

Therefore:

> **Don't summarize = display the original value rather than aggregating it.**

# 18. Step 13 — Copy Formatting Using Format Painter

The instructor wants the new Table Visual to have formatting consistent with the existing Matrix Visual.

Power BI's **Format Painter** can be used for this.

### Process

1. Select the existing Matrix Visual whose formatting you want to copy.
2. Go to the **Home** tab.
3. Click **Format Painter**.
4. Click the newly created **Table Visual**.

The formatting from the Matrix is applied to the Table Visual.

### Important concept

**Format Painter copies visual formatting, not the data configuration.**

So:

* The Table remains a Table.
* Its fields remain its own fields.
* Only compatible formatting is transferred.

# 22. Power BI Sync Prompt

When the slicers are pasted, Power BI displays a prompt asking whether the visuals should be synchronized.

The meaning is important.

If the slicers are synchronized:

> A selection made in a slicer on one page can be reflected in the corresponding slicer on another page.

For example:

```text id="v4y9kf"
Page 1
Length = 5.5
       ↓
Sync
       ↓
Page 2
Length = 5.5
```

The same filtering selection can therefore be maintained across pages.

---

# 23. Step 17 — Choose "Don't Sync"

In this session, the instructor **does not want the slicers synchronized**.

Therefore, when Power BI asks whether to sync the visuals:

Select:

**Don't Sync**

This means the slicers on the new page will operate independently.

---

# 24. What Happens If You Choose Sync?

The transcript explicitly explains the alternative.

If you choose to **Sync** the slicers:

* A selection made on one page can automatically be reflected on another page.
* The filter selection can remain consistent across the pages.

For example, selecting a particular Length range on Page 1 could cause the corresponding Length slicer on Page 2 to have the same selection.

But this is **not desired for this particular report design**, so the instructor chooses **Don't Sync**.

# 30. Key Power BI Concepts From This Session

## A. Calculated Table

A DAX expression can create an entirely new table inside Power BI.

The process is:

**Modeling → New Table → DAX → Enter**

This is different from creating a **measure**.

### Measure

Used primarily to calculate a value dynamically.

### Calculated Table

Creates a new table containing rows and columns.

In this session, the DAX expression creates the **Top Ten Diamonds** table.

---

# 31. Table Visual vs Matrix Visual

The session uses both:

### Matrix Visual

Previously used for the heat-map visualization.

### Table Visual

Used here to display detailed Top 10 diamond records.

A Table Visual is useful when you want to show individual records and their attributes directly.

---

# 32. Don't Summarize

This is one of the most important concepts from the session.

When a numerical field is added to a visual, Power BI may automatically aggregate it.

Examples:

* Sum
* Average
* Minimum
* Maximum
* Count

For a detailed Top 10 table, aggregation is undesirable.

Therefore:

**Field dropdown → Don't Summarize**

This ensures that the individual values are displayed.

---

# 33. Format Painter

**Format Painter** allows formatting from one visual to be copied to another.

In this session:

```text id="b6e4bz"
Existing Matrix
      ↓
Format Painter
      ↓
Top Ten Diamonds Table
```

This helps maintain a consistent design throughout the report.

---

# 34. Slicer Synchronization

Slicer synchronization controls whether the same filter selections are shared across report pages.

### Sync

Selections can be reflected across corresponding slicers on multiple pages.

### Don't Sync

Each page's slicer works independently.

In this session:

> **Don't Sync** was selected.

---

# 35. Why Copy Existing Slicers?

Instead of recreating the Length, Width, and Height slicers from scratch, the instructor copies them from the previous page.

Advantages:

* Saves time.
* Maintains the same slicer configuration.
* Preserves the existing appearance.
* Keeps the report design consistent.

# 36. Final Learning Summary

The session demonstrates how to create a **Top 10 Diamonds detail section** using a DAX-generated calculated table.

The major steps are:

1. Copy the recommended DAX expression from the PDF.
2. Go to **Modeling → New Table**.
3. Paste the DAX expression.
4. Press **Enter** to create the calculated table.
5. Open **Table View** and verify the new table.
6. Rename the table to **Top Ten Diamonds**.
7. Return to **Report View**.
8. Insert a **Table Visual**.
9. Add **Carat**.
10. Set Carat to **Don't Summarize**.
11. Add **Price**.
12. Set Price to **Don't Summarize**.
13. Optionally add **Color** or other columns.
14. Use **Format Painter** to copy formatting from the existing Matrix.
15. Copy the existing **Length, Width, and Height** slicers.
16. Paste them onto the new page.
17. When prompted about synchronization, select **Don't Sync**.
18. Position and resize the slicers.
19. Resize and position the Top Ten Diamonds table.
20. The report page now contains a detailed Top 10 Diamonds section with independent slicers.

### One-line revision

> **Create a calculated Top 10 table using DAX → display it with a Table Visual → set numerical fields to Don't Summarize → copy formatting with Format Painter → copy Length/Width/Height slicers → choose Don't Sync → arrange the page.**
