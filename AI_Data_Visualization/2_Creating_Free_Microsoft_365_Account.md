# Power BI Organizational Account — Detailed Notes

## 1. Why Do We Need an Organizational Account?

To create and use a **Power BI account**, particularly when working with **Power BI Service / cloud**, an **organizational or school account** is required.

A normal personal email account such as:

```text
@gmail.com
@yahoo.com
@hotmail.com
```

cannot be used in the same way to create the required Power BI organizational account.

Therefore, the lecture demonstrates how to create an **organizational account through Microsoft 365 setup**.

### Why is this important?

The organizational account will later be used for:

* Creating a Power BI account
* Accessing Power BI Service
* Publishing reports to the cloud
* Working with Power BI online

The current lecture focuses on **creating the organizational account**, while the next lecture will use that account to create the Power BI account.

# 23. Why This Account Is Required for Power BI

The reason for going through this somewhat lengthy process is that Power BI has both desktop and cloud/service components.

The basic development workflow is:

```text
Power BI Desktop
       ↓
Create Report
       ↓
Save .PBIX
       ↓
Publish to Power BI Service
       ↓
Cloud
```

When you want to **publish reports to Power BI Service**, you need an appropriate organizational account.

Therefore:

> **Organizational account → Power BI account → Power BI Service → Publish reports**

The next lecture will demonstrate how to create/use the **free Power BI account using the organizational account created in this session**.

---

# 24. Power BI Desktop vs Organizational Account

This distinction is important.

| Item                       | Purpose                                                     |
| -------------------------- | ----------------------------------------------------------- |
| **Power BI Desktop**       | Desktop application used to develop reports and data models |
| **Organizational Account** | Microsoft identity used for organizational/cloud services   |
| **Power BI Service**       | Cloud-based Power BI platform                               |
| **PBIX**                   | File format used to save Power BI Desktop reports           |

So, installing Power BI Desktop and creating an organizational account are **two separate setup activities**.
