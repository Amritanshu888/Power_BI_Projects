# Power BI Account Creation & Free Trial Activation — Detailed Notes

## 1. Purpose of This Session

In the **previous session**, an organizational Microsoft account was created.

In this session, that organizational account is used to:

* Create/access a **Power BI account**
* Sign in to Power BI
* Complete the initial Power BI setup
* Activate the **Power BI free trial**
* Prepare the account for publishing Power BI reports to the cloud

The organizational account created in the previous session is therefore the foundation for the Power BI account.

---


# 22. Power BI Desktop vs Power BI Account

This lecture builds on the previous installation lecture, so keep these concepts separate.

| Component                            | Purpose                                                    |
| ------------------------------------ | ---------------------------------------------------------- |
| **Power BI Desktop**                 | Desktop application used to develop reports                |
| **Organizational Microsoft Account** | Microsoft identity created for organizational/cloud access |
| **Power BI Account**                 | Account used to access Power BI services                   |
| **Power BI Service**                 | Cloud platform where reports can be published and accessed |
| **`.pbix`**                          | Power BI Desktop report file                               |

### Simple understanding

Think of it as:

```text
Power BI Desktop
      ↓
Build the report
      ↓
Save .PBIX
      ↓
Power BI Account
      ↓
Power BI Service
      ↓
Publish/share/access report
```
